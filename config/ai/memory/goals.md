# Goals & Vision

## Purpose
Maintain durable long-term goals, not temporary tasks.

## Current direction
- Build scalable digital businesses.
- Build reusable AI-first systems.
- Prefer assets over one-off services.
- Combine software, AI, ecommerce, SEO and marketing into integrated platforms.

## Decision filter
Before starting new work ask:
1. Can it become a reusable asset?
2. Can it be automated?
3. Can interns or AI operate it?
4. Will it scale internationally?
5. Does it improve long-term enterprise value?
