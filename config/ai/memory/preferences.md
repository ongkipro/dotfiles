# Memori: Preferensi user (fantastico)
> Bagian dari memori bersama.

- Bahasa: Indonesia (boleh campur istilah teknis Inggris).
- Prioritas: ringan, cepat, simpel, terminal-first.
- Install: utamakan no-sudo (mise). sudo hanya kalau memang butuh sistem.
- Tampilan terminal: prompt PLAIN tanpa Nerd Font/ikon (Nerd Font pernah dihapus karena bikin huruf melebar/tidak jelas).
- Browser: chromium (develop), brave (harian), chrome (login Google). Firefox & anydesk dihapus.
- Suka dijelaskan ringkas + langkah jelas; minta konfirmasi sebelum aksi yang sulit dibalik.
