Project **AUSSIE Sawit Malaysia** (`aussiesawit.my`) — landing + checkout COD untuk rawatan pokok sawit (Ganoderma/pokok kuning). Produk: `Baja Aussie` (Scalev id `406629`), varian 500ml (RM93) & 1 Liter (RM170).

- Repo: `ongkipro/aussie-malaysia` (GitHub, private). Clone lokal: `~/Projects/aussie-malaysia` (dibuat 2026-07-08).
- Stack saat ini: Astro 6 SSR + Tailwind 4 + Cloudflare Workers (Wrangler 4). Order → Scalev v2 `/order` + Meta CAPI Purchase. Satu-satunya route SSR: `src/pages/api/submit-lead.ts`; sisanya prerender statik.
- Konten Bahasa Melayu (`lang="ms"`), harga MYR. Script interaktif live di `public/scripts/` (BUKAN `src/scripts/`).
- Secrets: `SCALEV_API_KEY`, `SCALEV_STORE_UNIQUE_ID`, `META_ACCESS_TOKEN` dll — via `wrangler secret put`, jangan commit. Dev: adapter CF `undefined` → env TIDAK auto-load; export shell var.

**Rencana user (2026-07-08):** bangun **admin/backend sendiri ala mini-Shopify** (adaptasi pasar Malaysia/COD): kelola order, produk/harga/konten, dashboard analitik, multi-user (owner/admin/staff, admin terisolasi per peran). Untuk SEKARANG: **Cloudflare-native** (Workers/Pages + D1 + R2 + Cloudflare Access) — dipilih demi cepat & murah untuk satu project; VPS+Coolify disimpan untuk keputusan armada masa depan.

**Shipping/fulfillment: integrasi EasyParcel** (agregator kurir Malaysia, Open API **2026-06**). Kontrak **sudah diverifikasi** dari repo resmi `easyparcel/OpenAPI` (`source/includes/2026-06/`) → didokumentasikan di `docs/EASYPARCEL.md` (sumber kebenaran). Autocomplete alamat jalan opsional pakai Google Places dll.
