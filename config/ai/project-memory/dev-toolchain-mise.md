**~/.bashrc changes:**
- nvm **lazy-loaded**: node bin globbed onto PATH directly (claude/pi/codex available instantly), `nvm.sh` only sourced when `nvm` is first called. Cut bash startup 0.26s → 0.08s.
- mise block: exports `~/.local/share/mise/shims` to PATH (so tools resolve in scripts / non-interactive / VSCode tasks) **then** `eval "$(mise activate bash)"` (interactive per-dir versions). Both needed — activate's hook alone doesn't cover non-interactive shells. Placed before a guarded `# >>> dev-tools setup (claude) >>>` block (zoxide/fzf/direnv hooks, eza aliases, bat MANPAGER).
- Gotcha: a tool must be in `~/.config/mise/config.toml` (`mise use -g <tool>`) or shims refuse it ("not currently active"). Installing without `use -g` leaves it inactive.
