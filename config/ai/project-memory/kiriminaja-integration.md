KiriminAja (Indonesia multi-courier aggregator) integration in [[tokophi-project]] — platform-managed shipping (ADR 0004: config in super-admin, output in client admin).

**Sandbox**: base `https://tdev.kiriminaja.com` (prod `https://client.kiriminaja.com`). Auth: `Authorization: Bearer {key}` + Accept/Content-Type `application/json`. Sandbox key stored in **gitignored** `.env.local` + root `.env` as `KIRIMINAJA_API_KEY` / `KIRIMINAJA_ENV` (NOT committed; `.env.example` has a placeholder). Docs: developer.kiriminaja.com/docs; exact endpoints came from the **Postman collection** (community docs at `ongkipro/kiriminaja-documentation` abstract the paths; the official portal hides them).

**Exact endpoint contract — the API router takes the LAST path segment as the endpoint name, and the version prefix VARIES per endpoint** (this is the non-obvious part — a uniform `/api/mitra/v6/` fails with `{"status":false,"text":"Unable to find your endpoint target"}`):
- Pricing express: `POST /api/mitra/v6.1/shipping_price` — body `{origin, destination (kecamatan/district IDs), weight (g), item_value, insurance, courier[]}` → `results[]` (service_name, cost, etd, cod).
- Address search (name→ID, the linchpin): `POST /api/mitra/v2/get_address_by_name` — `{search}` → `data[]` `{id (kecamatan), text}`.
- Coverage: `POST /api/mitra/{province|city|kecamatan|kelurahan}` (unversioned).
- Create order express (→ AWB/resi): `POST /api/mitra/v6.1/request_pickup` (NON-COD) / `v5/request_pickup` (COD) — needs sender {address,phone,name,kecamatan_id,kelurahan_id,lat,lng} + schedule + `packages[]` {destination_*, weight, dims, service, ...}.
- Tracking: `POST /api/mitra/tracking` `{order_id}`. Cancel: `POST /api/mitra/v3/cancel_shipment?awb=&reason=`. Pickup schedule: `POST /api/mitra/v2/schedules`. Courier list: `GET /api/mitra/courier_services`.
