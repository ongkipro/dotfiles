## Intent triggers

Use the toolkit even if Cloudflare is implied rather than named, for example:

- edge API on Cloudflare
- move this endpoint to Workers
- add storage binding
- set up a Worker with D1
- review this wrangler config
- scaffold a Hono Worker

## Non-conflict rule

If a platform already has a more specific native skill for the exact task, use that native skill first, then use this toolkit as the consistency layer.
