## Do NOT activate first for these

These are better handled by existing non-dev Shopify workflows if the user intent is operational/store admin rather than app development:

- add Shopify products
- bulk import catalog
- edit Shopify page/blog/nav
- set up Shopify Admin API access only
- manage Shopify store content
- update store menus or redirects

## Use this router when

- the user is building or debugging a Shopify app
- the user needs Shopify code/schema/config validation guidance
- the user asks about Hydrogen, Functions, Liquid, GraphQL, or extensions
- the user needs help deciding whether the official Shopify AI Toolkit should be used
