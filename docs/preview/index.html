Private engineering control plane

One environment. Five AI runtimes. One source.

This repository is a terminal-first development environment and shared AI engineering kernel for Linux and macOS. It owns the configuration, policy, capabilities, routing, evidence, and recovery paths that must remain consistent across machines and AI CLIs.

What the repository owns

01 / Environment

Shell and toolchain

Shell startup, terminal, editor, Git, tmux, package-tool, and CLI configuration shared across supported machines.

02 / Policy

Cross-CLI operating rules

One canonical policy consumed by Claude Code, Codex, Pi, Antigravity, and OMP through runtime-specific paths.

03 / Capability

Owned AI skills

Provider-neutral methodology in skills/local, reconciled into every runtime without duplicating its source.

04 / Orchestration

OMP routing

Risk-aware work classification, specialist assignment, fallback policy, and device-specific overlays.

05 / Evidence

Delivery and learning

Project contracts, immutable run provenance, release gates, and reviewed promotion of reusable lessons.

06 / Recovery

Portable bootstrap

Linux and macOS installers, device inventory, health checks, fixture tests, and recovery runbooks.
