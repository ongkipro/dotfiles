# Modes and Channel Routing

| Mode | Primary objective | Protect most carefully |
|---|---|---|
| Article | Understanding and retention | Facts, argument, citations |
| SEO | Intent satisfaction and discoverability | Queries, entities, headings |
| Landing page | Conversion | Offer, proof, CTA, conditions |
| Ads | Attention and qualified action | Claim, limit, destination match |
| Email | Response or action | Context, relationship, ask |
| Social | Attention and engagement | Voice, hook, platform fit |
| Ecommerce | Purchase confidence | Product facts, variants, policies |
| Technical docs | Correct task completion | Identifiers, requirements, examples |
| PRD/RFC/ADR | Shared decision and execution | Scope, decisions, constraints |
| Prompt | Reliable model behavior | Instructions, schema, precedence |
| Investor | Credibility and decision support | Metrics, assumptions, projections |

For mixed documents, identify one primary objective and treat the others as constraints.
