## Retrieval policy

Durable method stays in this skill: HTML-first rendering, progressive enhancement, one authoritative commerce owner, explicit responsive transformations, product-first performance, and executable browser evidence. Volatile API syntax, Theme Store starter requirements, Shopify limits, plan access, checkout targets, deprecations, and account terminology must be retrieved at implementation time.
