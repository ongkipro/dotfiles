# Astro i18n

Use for multi-language Astro sites (typical set: Indonesian `id`, Malay `ms`,
English `en`). Astro's built-in i18n routing is enough for most sites; do not
add an i18n library until a dictionary or plural requirement proves it is
needed. Config keys and helpers are version-sensitive: verify against the
installed Astro version and the official guide before writing config.

## Locale routing

- Configure `i18n.locales` and `i18n.defaultLocale` in `astro.config.*`. Folder
  structure under `src/pages/` must mirror the URL structure for every locale.
- Pick `routing.prefixDefaultLocale` once and keep it: `false` keeps the default
  locale at `/about/`, `true` puts every locale under its prefix. Changing it
  after launch is a URL migration that needs redirects (hand off to
  `seo-website-builder`).
- Use `i18n.fallback` (redirect or rewrite) only for pages genuinely not yet
  translated; a fallback page must not claim the missing locale in `lang` or
  hreflang.
- Build every internal link with `getRelativeLocaleUrl()` /
  `getAbsoluteLocaleUrl()` from `astro:i18n`; never string-concatenate locale
  prefixes.
- `Astro.currentLocale` comes from the URL and works on static pages.
  `Astro.preferredLocale` reads the request's `Accept-Language`, so it needs
  on-demand rendering. Never auto-redirect crawlers by browser language;
  offer a visible language switcher instead.
- Per-locale domains (`i18n.domains`) require server output and `site`; treat
  that as a deployment decision, not a default.

## Dictionaries

- Keep UI strings in one typed module per locale (for example
  `src/i18n/{id,ms,en}.ts` exporting the same key shape) and a `t(locale, key)`
  helper. The default-locale file is the type source; a missing key in another
  locale must fail `astro check`, not render `undefined`.
- Long-form content belongs in content collections with a `locale` field or a
  per-locale folder, not in dictionaries. Client-edited content routes to
  `cms-content`.
- Indonesian and Malay are distinct locales with different vocabulary; never
  serve one as the other's translation without review.
- Ship dictionaries to islands only as the few keys that island needs; passing
  the whole dictionary serializes it into the HTML.

## Formatting

Dates, numbers, currency, plural rules, and relative time use `Intl` (see
`native-first`): `Intl.NumberFormat('id-ID', { style: 'currency', currency:
'IDR' })`, `Intl.DateTimeFormat`, `Intl.PluralRules`. Pass the page locale
explicitly; never rely on the server or browser default locale.

## SEO handoff

Set `<html lang>` from `Astro.currentLocale`. Hreflang alternates (including
`x-default`), per-locale canonical URLs, localized sitemaps, and translated
metadata policy are owned by `seo-website-builder`; this skill only provides
the URL helpers and layout slot that emit them.
