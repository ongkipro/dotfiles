# SEO and Content Sites

For public websites, build SEO in from the start.

## Always include

- page-specific title
- page-specific meta description
- canonical URL
- Open Graph/Twitter metadata
- semantic heading structure
- sitemap
- robots.txt
- internal links

## Content rules

- write real content, not filler
- map each page to a clear user intent
- avoid duplicate titles/descriptions
- use structured data where helpful
- support image alt text and accessible markup

## Common page types

- home
- service/feature page
- article/post page
- category/tag page
- contact page
- location page

## For local/business sites

Also think about:
- trust signals
- clear CTA paths
- contact info consistency
- local schema when relevant
