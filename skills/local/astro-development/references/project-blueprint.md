# Project Blueprint

Before implementation, define:

## 1. Site type
- marketing site
- docs site
- blog/content hub
- local business site
- hybrid product site

## 2. Page map
- home
- about
- services/features
- blog/docs index
- detail routes
- contact / CTA pages
- legal pages

## 3. Content model
- collections needed
- frontmatter/schema shape
- taxonomy: tags, categories, authors, locales

## 4. Interactivity map
- what can stay static
- what needs a client island
- what needs server behavior

## 5. SEO/content plan
- page intent
- keyword/topic mapping
- schema types
- internal links

## 6. Deployment target
- Vercel
- Netlify
- Cloudflare
- Node/container

For existing projects, first audit current structure before changing architecture.
