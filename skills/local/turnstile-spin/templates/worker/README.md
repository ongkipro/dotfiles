# Archived Worker template

This directory is retained as a historical upstream artifact and is not part of the supported Turnstile Spin flow. Spin adds Siteverify to the customer's existing server-side request handler and must not copy, install, test, or deploy this template.

Do not use the files in this directory as an implementation fallback. If the protected request has no existing server-side handler or hook, stop and explain that secure Turnstile validation requires one outside this skill's scope.
